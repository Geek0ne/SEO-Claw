# 域名黑名单 —— 公开体检服务不扫这些目标
#
# ⚠️ 这个文件的作用不是「技术上拦得住什么」，而是**责任隔离**。
# 有人嫌自己抓得慢，在我们的页面填上别人的域名，让**我们的服务器**
# 去反复抓。被投诉的是我们的 IP，被目标站封的也是我们的 IP。
#
# 两种加法：
#   1. 改这个文件（每请求读一次，改完**立即生效，不用重启**）
#   2. 环境变量 SEO_DENYLIST（逗号分隔，适合容器部署）
#
# 格式：一个域名一行。`#` 后面是理由——三个月后你早忘了为什么加这条，
# 注释是唯一的线索。支持子域：写 example.com 会连 a.example.com 一起挡。

# ─── 对方主动要求停止（最常见的来源：abuse 投诉邮件）───────────────────
# 2026-10-03 收到对方站方邮件，明确要求停止访问。
# competitor.example

# ─── 已知的攻击目标 / 高风险目标 ────────────────────────────────────
# 把别人的登录页、后台管理页拿去做压力测试的，都是滥用。
# scanner.example

# ─── 法律与合规 ──────────────────────────────────────────────────
# 明确不希望被第三方抓取的站点（robots 已声明但仍需硬拦的）：
# privacy-sensitive.example

# ⚠️ 本文件为空时**不会**变成「全部拒绝」——那是服务直接不可用。
# 没有配置时，所有通过 SSRF 校验的域名都放行。
