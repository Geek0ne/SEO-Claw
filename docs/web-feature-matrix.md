## 设计系统

界面按 `DESIGN.md`（唯一事实来源）重建：纸白底、墨黑字、琥珀唯一强调色、
印章红仅用于严重级徽标、零阴影、圆角 2px/4px、数字与规则编号等宽体、
健康分为**带刻度的量规**（0–100 十一道刻线 + 墨黑指针）、
颜色永不单独表意、focus-visible 保留、触摸目标 ≥44px、尊重
`prefers-reduced-motion`。零外部依赖（无 CDN / 字体 / 框架）。
